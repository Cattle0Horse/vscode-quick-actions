# 快捷操作

通过 VS Code 命令面板或自定义快捷键执行常用操作。

## 复制当前文件

在命令面板运行 **Quick Actions: 复制当前文件到系统剪贴板**（`quickActions.copyCurrentFile`）

- 复制已保存到磁盘的文件，不自动保存编辑
- 差异编辑器使用右侧文件
- 虚拟内容、远程文件和已删除文件无法复制

## 复制文件路径

在命令面板搜索 **Quick Actions**：

| 命令             | 命令 ID                             |
| ---------------- | ----------------------------------- |
| 复制文件路径     | `quickActions.copyFilePath`         |
| 复制文件相对路径 | `quickActions.copyRelativeFilePath` |

- 复制纯文本路径，不带行号；支持普通本地文本文件、内置 Git 暂存/未暂存/合并冲突文本差异和 Git Graph 历史文本内容。
- 使用当前聚焦的文本编辑器，差异编辑器取当前聚焦的一侧；Git Graph 按记录的仓库和文件路径解析，不复制展示用的 `file.json`。
- 相对路径以文件所属工作区目录为基准，多根工作区不添加工作区名称；工作区外文件回退为绝对路径。
- 历史文件即使已删除也可复制路径；不保存编辑。无文本编辑器、未命名文件、其他虚拟内容或 Git Graph 路径无效时提示并保留剪贴板。

## 复制当前文件路径及行号

在命令面板搜索 **Quick Actions**：

| 命令                       | 输出示例                    | 命令 ID                                            |
| -------------------------- | --------------------------- | -------------------------------------------------- |
| 复制当前文件绝对路径及行号 | `C:\project\src\main.ts:42` | `quickActions.copyCurrentFileAbsolutePathWithLine` |
| 复制当前文件相对路径及行号 | `src/main.ts:42`            | `quickActions.copyCurrentFileRelativePathWithLine` |

- 复制纯文本，行号从 1 开始，取当前光标所在行；选中多行时仍只复制光标行号。
- 相对路径以文件所属工作区目录为基准，多根工作区不添加工作区名称；工作区外文件回退为绝对路径。
- 使用当前聚焦的文本编辑器，差异编辑器取当前聚焦的一侧及该侧光标行号；支持内置 Git 暂存、未暂存、合并冲突文本差异和 Git Graph 历史文本内容，路径指向对应的本地文件。
- 历史文件即使已删除也可复制路径；不自动保存编辑或修改暂存区。未命名文件、无法解析本地路径的虚拟内容和无文本编辑器时提示原因并保留剪贴板。

## 打开当前文件 Git 差异

在命令面板搜索 **Quick Actions**，选择需要的比较方式：

| 命令                            | 左侧 → 右侧                                   | 命令 ID                         |
| ------------------------------- | --------------------------------------------- | ------------------------------- |
| 打开当前文件 Git 差异（未暂存） | 暂存区 → 工作区                               | `quickActions.openUnstagedDiff` |
| 打开当前文件 Git 差异（HEAD）   | 最近一次提交 → 工作区，包含已暂存和未暂存修改 | `quickActions.openHeadDiff`     |
| 打开当前文件 Git 差异（已暂存） | 最近一次提交 → 暂存区                         | `quickActions.openStagedDiff`   |
| 打开当前文件 Git 差异（自动）   | 优先未暂存差异，否则查看已暂存差异            | `quickActions.openGitDiff`      |

- 未保存的编辑视为工作区修改，直接显示缓冲区内容，不自动保存。
- 已暂存命令只显示暂存区内容，不受未保存编辑影响。
- 新文件与空文本比较；已暂存重命名使用旧路径的 HEAD 内容。
- 可从 Git Graph 历史提交的文本差异编辑器跳转到当前仓库对应文件的差异。
- 没有差异、不在 Git 仓库、Git 未启用或存在合并冲突时提示原因。

使用原生文本差异编辑器。可按个人偏好设置左右或上下布局。首版面向桌面本地文本文件；不提供二进制专用比较、Notebook 结构差异或合并冲突处理。

## 切换 Git 暂存状态

在命令面板搜索 **Quick Actions**：

| 命令                      | 命令 ID                             |
| ------------------------- | ----------------------------------- |
| 切换当前 Git 块暂存状态   | `quickActions.toggleGitHunkStaging` |
| 切换当前文件 Git 暂存状态 | `quickActions.toggleGitFileStaging` |

- 支持普通文件、内置 Git 未暂存/已暂存文本差异，以及新增暂存文件的单页只读视图；差异左右两侧均可执行。
- 未暂存差异执行暂存，已暂存差异和暂存单页执行取消暂存。普通文件的文件命令优先暂存剩余修改，否则取消整个文件暂存。
- 块命令处理主光标所在的完整连续改动块，使用聚焦侧的行号，不按选区裁剪。普通文件优先暂存该处未暂存块，否则取消该处已暂存块；其他改动块保持原暂存状态。删除块可将光标放在删除位置的前一行，文件开头的删除放在第一行。
- 只修改暂存区，不修改磁盘或编辑缓冲区。暂存前要求目标文件已保存；已暂存视图取消暂存可以保留工作区里的未保存编辑。
- 文件命令也可从 Git Graph 历史文本视图定位到当前工作区文件；块命令不处理无法可靠映射行号的历史差异。合并冲突、没有改动或光标不在改动块中时提示原因。
- 可在键盘快捷方式中分别绑定上述命令，扩展不占用默认按键。

## 从 Git 差异打开源文件

运行 **Quick Actions: 从 Git 差异打开源文件**（`quickActions.openDiffSourceFile`），统一支持 VS Code 内置 Git 与 Git Graph 的文本差异编辑器。

- 打开差异右侧对应的当前工作区文件；已暂存差异也打开当前文件，保留未保存编辑。
- 支持内置 Git 将新增暂存文件打开的单页只读文本视图，跳转到对应的工作区源文件。
- 支持内置 Git 三栏冲突合并编辑器，从当前、传入或结果栏打开对应的工作区源文件；临时合并结果保留在合并编辑器中，不自动写入源文件。
- 跳转到当前聚焦侧的光标行、列；使用相同行号，不按版本内容重新映射。位置超出当前文件范围时收敛到有效位置。
- Git Graph 历史差异按其记录的仓库与文件路径定位，不会打开展示用的 `file.json`。
- 不保存文件或修改暂存区；Git Graph 文件已删除或路径无法解析时提示原因。

可为该命令绑定同一个快捷键，例如：

```json
{
  "key": "ctrl+alt+o",
  "command": "quickActions.openDiffSourceFile",
  "when": "isInDiffEditor || isMergeEditor || resourceScheme == git"
}
```

## 自定义快捷键

在键盘快捷方式中搜索上述命令 ID，可为各命令分别绑定自己的按键。扩展不占用默认快捷键。例如为自动模式在 `keybindings.json` 中添加：

```json
{
  "key": "ctrl+alt+d",
  "command": "quickActions.openGitDiff",
  "when": "editorTextFocus"
}
```
